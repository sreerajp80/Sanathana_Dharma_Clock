## What changed

Added the location layer: a way to get the device position, save it, and pick which
place the clock runs from — without ever going online or crashing when there is no
location.

### New source files

- `lib/services/location_service.dart` — `LocationService`. Wraps
  `GeolocatorPlatform.instance`. Checks the location service is on, checks/requests the
  permission **at the point of use**, and returns the current fix as a `LocationResult`
  (with a `LocationStatus` enum: success, serviceDisabled, permissionDenied,
  permissionDeniedForever, error). It **never throws** to the caller — any plugin error
  becomes `LocationStatus.error`. It holds no prefs, no `BuildContext`, no UI strings.
  The `GeolocatorPlatform` can be injected for tests. `toString` omits coordinates.

- `lib/repositories/location_repository.dart` — `LocationRepository`. The only place that
  reads/writes the saved location and the "use live location" flag in
  `shared_preferences` (keys from `AppConstants`). Reads are defensive: a missing or
  corrupt record returns `null` (location) or `false` (flag). Includes
  `clearSavedLocation()` for the future Settings "clear" action.

- `lib/services/location_resolver.dart` — `LocationResolver`, a pure helper (no plugins,
  no prefs) for the fallback chain **live → saved → none**. Returns an `EffectiveLocation`
  (latitude, longitude, source) or `null` when there is no anchor at all; the caller then
  uses a midnight-anchored day, which `SolarCalculator` already produces.

### Android config

- `android/app/src/main/AndroidManifest.xml` — added `ACCESS_COARSE_LOCATION` and
  `ACCESS_FINE_LOCATION`, and set `android:allowBackup="false"` on `<application>` so the
  saved location is not copied to Android cloud backup (security.md §10). No `INTERNET`
  permission was added, and none is present.

### Tests

- `test/repositories/location_repository_test.dart` — write/read round-trip, missing key
  → `null`, corrupt/wrong-shape JSON → `null`, `clear` removes the record, use-live flag
  default and toggle (uses `SharedPreferences.setMockInitialValues`).
- `test/services/location_resolver_test.dart` — the fallback chain: live wins when
  `useLive` + success; falls back to saved when live is off, failed, or absent; `null`
  when nothing is available.
