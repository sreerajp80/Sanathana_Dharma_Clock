# Plan: "Hora" tab — planetary hours

**Status:** completed

## What the user asked for

A new bottom tab named **Hora**. Horā = planetary hours: 12 horās of the day
(sunrise → sunset) and 12 of the night (sunset → next sunrise), each ruled by
one of the 7 classical planets. The first horā of the day is ruled by the
weekday's lord; the rest cycle through the fixed horā order. The tab shows a
clear "Current horā: Śukra" readout on top, then the full 24-row list with the
current one highlighted.

(The user also mentioned an outer ring on the dial as an alternative. This plan
builds the tab only; a dial ring can be a later plan if wanted.)

## The issue

The app has no horā math and no Hora tab. Sunset math already exists
(`SolarCalculator.sunsetUtc`, added for the Muhurta tab), and the clock already
resolves the sunrise-to-sunrise day — so all inputs are already there.

## The math (pure arithmetic, offline)

- Let `sunrise` and `span` be the clock's resolved day (same as the dial), and
  `nextSunrise = sunrise + span`. Let `sunset` come from `sunsetUtc`.
- **Day horās:** `D = sunset − sunrise`; horā `i` (0–11) runs
  `[sunrise + i·D/12, sunrise + (i+1)·D/12]`.
- **Night horās:** `N = nextSunrise − sunset`; horā `i` (0–11) runs
  `[sunset + i·N/12, sunset + (i+1)·N/12]`.
- **Lords:** the horā order (each hour's ruler) is the classic sequence
  `Sūrya → Śukra → Budha → Chandra → Śani → Guru → Maṅgala`, repeating.
  The first day-horā is the weekday lord:

  | Weekday | Lord |
  |---------|------|
  | Sunday | Sūrya (Sun) |
  | Monday | Chandra (Moon) |
  | Tuesday | Maṅgala (Mars) |
  | Wednesday | Budha (Mercury) |
  | Thursday | Guru (Jupiter) |
  | Friday | Śukra (Venus) |
  | Saturday | Śani (Saturn) |

  Horā `k` (0–23) of the day is `lords[(startIndex + k) mod 7]`. A built-in
  check of this rule: 24 mod 7 = 3, so the 25th horā (next sunrise) lands on
  the next weekday's lord automatically.
- Weekday = the local calendar weekday of the anchoring sunrise (same
  convention as the kāla tables).
- Splitting is done in microseconds with rounded boundaries, like
  `MuhurtaKalaCalculator`, so the 12+12 windows tile the day with no gaps.

**Fallback (hard rule 4 — never crash):** horās need a real sunset. With no
location or on a polar/fallback day, the calculator returns an empty list and
the screen shows the same friendly "needs a sunrise and sunset" message the
Muhurta tab uses. No fake windows.

## Files to change

| File | Change |
|------|--------|
| `lib/core/constants/hora_names.dart` | **New.** The 7 planet names (Sanskrit + English, e.g. "Śukra (Venus)"), the fixed horā order, and the weekday → starting-lord table. Pure constants. |
| `lib/models/hora_window.dart` | **New.** Immutable model: `lord` (display name), `isDay` (day or night horā), `start`, `end` (UTC), plus a `contains` check — mirrors `MuhurtaWindow`. |
| `lib/services/hora_calculator.dart` | **New.** Pure service: `horaList({sunrise, sunset, nextSunrise, weekday})` → the 24 `HoraWindow`s (empty when the daytime or night is not positive). No plugins, no UI. |
| `lib/providers/service_providers.dart` | Add `horaCalculatorProvider`. |
| `lib/providers/hora_providers.dart` | **New.** `horaDayProvider` — mirrors `muhurtaDayProvider`: watches the clock's anchor sunrise/span via `select` (recomputes once per day roll or location change, not per tick), computes sunset, returns the 24 horās or an empty list. |
| `lib/screens/hora_screen.dart` | **New.** The tab UI: a "Current horā" card on top (lord name, day/night, start–end, time remaining), then "Day horās" (12 rows) and "Night horās" (12 rows). Current row highlighted and scrolled into view on open; minute-precision watch like the Muhurta screen. Fallback message when the list is empty. |
| `lib/core/router.dart` | Add a fourth shell branch `/hora` → `HoraScreen`. |
| `lib/screens/home_shell.dart` | Add the fourth `NavigationDestination` ("Hora", e.g. `Icons.wb_twilight` icons). |
| `test/services/hora_calculator_test.dart` | **New.** Fixed 06:00–18:00–06:00 day: each horā is exactly 60 min; first day-horā lord matches the weekday for all 7 weekdays; the sequence follows the horā order; 24 windows tile sunrise → next sunrise with no gaps; non-positive daytime → empty list. |
