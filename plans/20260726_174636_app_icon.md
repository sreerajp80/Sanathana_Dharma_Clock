# App Icon for Sanathana Dharma Clock

**Status:** completed

## The issue

The app currently uses default placeholder launcher icons (`ic_launcher.png`). It needs a beautiful, custom Android icon reflecting the Sanathana Dharma (Vedic solar timekeeping) identity.

## Concept & Design

- Glowing golden Kalachakra (Vedic Wheel of Time) clock dial merged with a radiant rising sun at dawn.
- Central lotus and solar ray motifs.
- Deep rich cosmic dark background with warm gold/amber accents.
- Modern Android app icon aesthetics without text.

## Files to change

| File | Change |
|------|--------|
| `assets/icon/app_icon.png` | **New.** 1024x1024 master icon PNG image. |
| `pubspec.yaml` | Add `flutter_launcher_icons` to `dev_dependencies` and configure icon generator options. |
| `android/app/src/main/res/mipmap-*/ic_launcher.png` | Updated Android launcher icons for all density levels (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`). |

## The plan for the fix

1. Save the generated high-resolution artwork as `assets/icon/app_icon.png`.
2. Update `pubspec.yaml` with `flutter_launcher_icons: ^0.14.3` and launcher icon configuration.
3. Run `flutter pub get` and `dart run flutter_launcher_icons`.
4. Run `flutter analyze` and `flutter test` to ensure project health.
5. Create change log in `change_log/20260726_174636_app_icon.md`.
